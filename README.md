# Kasat Group of Companies (KGoC) - Corporate Website

The official corporate parent website for **Kasat Group of Companies (KGoC)**, establishing KGoC as the parent organization for:
1. **Emerge India & Overseas** (`https://emergeio.vercel.app/`)
2. **Kasat Virtual College of Education (KVCE)** (`https://kvce.vercel.app/`)

---

## 🎨 Brand Identity & Design System

- **Primary Magenta:** `#A50062`
- **Deep Magenta:** `#80004F`
- **Secondary Pink:** `#D52A91`
- **Light Pink:** `#FBEAF4`
- **Soft Background:** `#FFF9FC`
- **White Background:** `#FFFFFF`
- **Primary Text:** `#202033`
- **Secondary Text:** `#626273`

Decorative curved lines and horizontal stripes throughout the UI are directly inspired by the striped magenta KGoC logo.

## 🚀 Getting Started

### Development Server
```bash
npm run dev
```
Runs the Vite development server locally at `http://localhost:3000`.

### Production Build
```bash
npm run build
```
Generates the optimized static build in `/dist`.

### Preview Production Build
```bash
npm run preview
```
Previews the production build locally.
